# 压测报告模板

复制这一节，填好后放到发布记录里（或附在任务的交接记录里）。关键数字同步到 docs/performance.md 的“当前基线”。

## 标签服务压测报告 yyyy-MM-dd

**结论**：通过 / 不通过（一句话：哪项没达标、原因）

### 环境

| 项 | 值 |
| --- | --- |
| 服务器 | CPU 型号、核数、内存、磁盘（数据目录所在盘） |
| 操作系统 / 部署方式 | 如 Ubuntu 24.04 + Docker、Windows Server 2022 + Windows 服务 |
| 服务版本 | git 提交号、.NET 版本、Release / ReadyToRun |
| 配置 | `LabelService:Render:MaxConcurrency`、`QueueTimeoutMs`、日志级别 |
| 压测机 | 型号、和服务器之间的网络（同机房 / 跨网段、延迟） |
| 数据 | 模板（编码、版本）、输出格式、DPI、每张数据是否不同 |

### 结果

| 场景 | 并发 / 速率 | 时长 | 请求数 | 吞吐（次/秒） | 服务端 P50 | P95 | P99 | 最大 | 错误率 | 503 次数 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 单张，固定 60 次/秒 | 最多 50 并发 | 60 s | | | | | | | | |
| 单张，最高可持续速率 | | | | | | | | | | |
| 单张，饱和（MODE=saturate） | 50 并发 | 60 s | | | | | | | | |
| 批量 100 张合并 PDF | 4 并发 | 60 s | | | | | | | | |

（服务端耗时取 k6 输出的 `server_total_ms`；同时记下 `http_req_duration`，两者的差是网络。）
