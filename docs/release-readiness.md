# 定版核对清单

更新日期：2026-10-13。用户确认主要功能可能收敛，后续以小改进为主；本文汇总当前实现和待核对事项，**不代替用户的现场验收或正式发版决定**。

## 当前版本与边界

- 模板 JSON `schemaVersion` 和开放接口分别为 `1.0`、`/api/v1`。
- HTTP SDK 和 Windows 扩展为 `1.0.0-preview.5`，来源为 `client/Directory.Build.props`；未自动改成 `1.0.0`、打 tag 或发布到 NuGet。
- 单实例部署，SQLite 默认，SQL Server/PostgreSQL 可配置；换数据库不意味着支持多实例或自动迁移已有数据。
- 服务生成文件，调用方或 Windows SDK 提交打印；设备出纸、状态与补打业务由调用方和 Windows 队列管理。
- 包装标志由项目维护；用户上传图片作为素材，暂不开放标准标志库维护。

## 定版前需要核对

| 项目 | 当前事实 | 现场核对方式 |
| --- | --- | --- |
| USB 激光和小票打印机 | PNG/PDF 走驱动，ZPL 走 RAW；USB 接口本身不代表支持 ZPL | 实施配置默认打印机、纸张和方向，验证整批/单项/子集、尺寸、扫描与份数 |
| 客户电脑 | PDF 需要 Windows 8.1+ 系统引擎；现代 .NET 桌面集成使用 Windows 目标 | 实际目标 OS、Framework、x86/x64 和显示缩放上运行，不用开发机成功代替 |
| 生产部署 | Docker 和 Windows 服务部署说明已提供 | 在选定服务器安装、上传授权字体，确认 `/health/ready`、数据库升级和回滚 |
| 数据备份 | 内置 SQLite 每日备份包含主库、可选日志库和 `assets/` | `fonts/`、`branding/`、`admin-signing.key` 和部署配置需额外备份，演练恢复完整标签与品牌 |
| 性能 | 单张目标 P95 ≤ 100 ms；最近历史基线在改动前已有失败项 | 在空闲、同规格机器重跑基准；目标服务器做真实压测，单独决定是否重录基线 |
| SDK 发版 | 当前仍为 preview.5，内部包未签名 | 确认客户目标框架、分发方式、是否签名及正式版本号，再执行发布流程 |
| 权限与日志 | 现有实现和权限边界保留 | `sys.user`/`sys.role` 按高信任管理权限发放；操作日志业务范围是否需额外限制另立任务 |
| 运维监控 | 已提供 Prometheus/Grafana 样例，CI 自动流程尚未接入 | 正式抓取、告警去向、日志保留天数、备份位置由部署负责人确认 |

最近字段来源改动的 18 项前后基准比较有一项全量结果超过 20%，单项复测回到约 7%；这不能把全量门禁标成通过，也不能证明明显提速。完整记录在 [性能约定](performance.md) 和 [字段来源任务](tasks/T-052-field-sources.md)，此次文档整理不调整基线。

## 维护原则

1. 小优化单独开任务，注明影响范围并跑相应检查；接口、SDK 公共 API 和驱动行为保持兼容。
2. 功能验收、性能验收和实际设备验收分别记录，不用“准备定版”替代未完成的验证。
3. 保存模板发布版本和已生成文件；SDK 集合补打使用原内容，不因补打重新生成当前日期或新模板版本。
4. 现场发现新需求再排到 [后续候选](roadmap.md)，当前版本不提前承诺 TSPL、发号、表格、多实例等功能。
