# 后续候选

这些是当前定版之外的方向，不代表已排期。现有生成、设计、管理、A4 拼版、SDK 集合补打和 Windows 静默打印已经实现，主入口不再把它们列成待开发功能。

## 使用反馈驱动的小改进

- 常用包装、物流和行业标志：由项目选择合法、明确的标准素材维护进库；当前用户上传图片仍作为素材。
- 实施与对接体验：更直观的驱动配置说明、错误提示、调用样例、打印选择和校准指引。
- 页面与兼容性：实际客户电脑、长字段名、缩放、窄窗口和大模板的具体问题。

每项先描述真实使用场景、验收方式和兼容影响，不把所有候选一次铺进当前界面。

## 需要独立设计的能力

| 方向 | 现有基础与需要增加的工作 |
| --- | --- |
| 原生 ZPL、TSPL 或其他设备指令 | 已有位图 ZPL；新增格式需明确打印机、字体、编码和扫码验证 |
| 流水号与发号 | 当前批量序号仅代表请求条目序号；持久发号需要并发、防重及审计设计 |
| 模板嵌套、表格、条件显示、计算表达式 | A4 拼版和固定模板已具备；新增元素、分页或表达式需单独评审，见 T-020 |
| 服务端打印代理与设备状态 | SDK 已可提交到本机驱动或网络 ZPL；远程代理、队列和回执另做 |
| 服务端打印记录与重新生成 | 目前调用日志不保存业务数据，客户端集合可原内容补打；服务端留档需数据与保留策略 |
| Excel/CSV 导入、更多语言 SDK、OpenAPI 描述 | 复用 HTTP 契约；分别评估使用单位的实际接入需求 |
| SSO、多租户、多实例 | 现有账号、角色、业务分组和单进程缓存；隔离、登录与缓存同步另行设计 |
| 异步大批量、回调 | 当前同步接口总张数上限 500；任务管理、文件存储和重试另做 |
| AI 辅助模板或复用到单据报表 | 模板 JSON 可复用；识别、富文本、表格和分页不在当前版本范围 |

如需采纳，先建任务，涉及跨部分、依赖或契约变化时按 [AGENTS](../AGENTS.md) 和 ADR 流程处理。
