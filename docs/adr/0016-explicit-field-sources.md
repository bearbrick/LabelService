# 0016 字段显式来源，模板提供的系统预设与手写值互斥

状态：已采纳（用户 2026-10-13 确认“系统预设和手写值分开，两者互斥，这个直接改了吧”）
日期：2026-10-13
关联：T-052、ADR 0012

## 决定

- 新增可选字段 source：input 表示仅接口输入，template 表示仅模板提供，忽略请求中的同名值。省略 source 的旧字段保持条目→公共字段→auto→default，不改已发布版本和 schemaVersion。
- template 字段只选择系统预设 auto 或手写 default，允许两项均为空；required 对模板提供不适用。input 不允许配置 auto/default。类型检查保留，手写文字不当表达式。
- 新界面主要提供当前日期、当前日期和时间。旧版的其他预设仍可显示及编辑既有参数，不批量删除旧配置。旧回退字段明确标为兼容模式，用户切换来源或重新设置值后使用新来源。
- 系统预设非空时清空并禁用手写值；选回“无”允许手写。模板提供不出现在调用样例，预览取模板配置；schema 和 SDK 返回 source。
- 字段表使用工作区全宽，调用样例和字段接口移到按钮抽屉；复用既有组件和样式，不新增依赖。

## 影响

这是新增可选属性，旧协议行为不变。新字段取值意图更明确，不能靠隐藏输入框实现后端强制来源。字段验证仍为一次字段遍历；本次只验证不退化，不承诺明显加速。发布期固定值预编译作为后续单独性能任务。
