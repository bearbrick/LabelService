# 0005 A4 拼版用独立的“版式”，模板嵌套放到二期

状态：已采纳
日期：2026-10-09
关联：T-018、T-019、T-020

## 背景

2026-10-09 确认 A4 拼版进初版：同一个标签模板，有时单张打（标签机），有时一次打很多张、拼在一张 A4 不干胶纸上（激光打印机）。排版方式希望是把已经做好的单张标签拖到 A4 纸上，方便对齐。

## 决定

- 新增“拼版版式”（sheet layout），和模板分开保存。一个版式记录纸张尺寸、格子尺寸、每个格子的位置（mm）和旋转（0、90、180、270）、填充顺序、打印偏移。
- 版式按格子尺寸和模板匹配：一个版式可以给所有同尺寸的模板用。模板本身不知道版式，单张打印不受影响。
- 版式在“拼版设计器”里画：把已发布的模板拖到纸上生成格子，复用模板设计器的吸附、对齐参考线、等间距分布；也可以按行列一键排满后再微调。
- 打印时由调用方选择：单张和批量接口增加可选参数 `layout`、`startSlot`，响应头增加 `X-Page-Count`，新增错误码 `LAYOUT_NOT_FOUND`、`LAYOUT_SIZE_MISMATCH`。不传 `layout` 时行为不变（向后兼容）。
- 拼版只输出 PDF 和 PNG；ZPL 面向热敏标签机，不支持拼版。
- 渲染：每个格子把画布平移、旋转到格子位置后，按单张流程绘制；不随数据变化的内容每页只计算一次。
- “把一个模板作为元素放进另一个模板”（模板嵌套）放到二期（T-020）。届时在发布时把嵌套展开成普通元素，生成时没有额外开销。

## 备选方案

- **只给参数、不做设计器**（行数、列数、边距、间距）：实现最简单，但不规则排列（比如旋转、错位）做不了，也不符合“拖拽对齐”的要求。保留为设计器里的“自动排列”功能。
- **做一个 A4 模板，里面嵌套多个标签模板**：拼版方式和模板绑死，同一个标签换一种纸就要再做一个模板；数据怎么分配给各个嵌套的标签也更复杂。
- **把拼版参数写进标签模板**：同一个标签可能用在不同规格的不干胶纸上，放进模板会产生很多副本。

## 影响

- 契约新增版式 JSON、两个请求参数、一个响应头、两个错误码，按 AGENTS.md §6.4 的向后兼容流程同步后端、调用端、前端和文档（T-018、T-019）。
- 数据库新增 `sheet_layout` 表，调用日志增加 `layout_code`。
- 性能预算：A4 一页不超过 24 张标签的 PDF，每页 P95 ≤ 250 ms（和 A4 唛头相同）。
- 排期：拼版放在 M3，和管理后台一起做，整体顺延。
