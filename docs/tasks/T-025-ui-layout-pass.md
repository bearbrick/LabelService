## 目标

管理后台、模板设计器、拼版设计器的每个页面和弹窗，以及 SDK 演示程序的窗口，在常见的窗口尺寸下都没有间距不齐、互相遮挡、文字截断、内容显示不全的问题；拖动改变窗口大小时布局跟着合理变化。

## 范围

可以新建、修改的文件：

- `frontend/src/**/*.vue` 的模板和样式、`frontend/src/style.css`、`frontend/src/admin.css`、`frontend/src/sheet.css`
- `frontend/tests/**`：能自动检查的显示规则（如有）
- `client/samples/LabelService.Demo.WinForms/**`：演示程序窗口的布局
- `frontend/README.md`、`client/README.md`：如有需要说明的尺寸约定

## 共享文件

## 验收标准

- [ ] 每个页面和弹窗在 1920×1080、1440×900、1280×720、1100×700（设计器的最小宽度）下逐个检查：没有横向滚动条（设计器画布除外）、没有被裁掉的文字（有意的省略号要能看到完整内容，如悬停提示）、没有互相遮挡、间距一致
- [ ] 管理后台的页面在窄屏（768 宽）下可以使用（模板树收起、表格可以横向滚动）
- [ ] 改变窗口大小时布局正常（设计器的面板、画布、标尺跟着调整）
- [ ] 演示程序窗口在最小尺寸和最大化时控件不被截断
- [ ] 修完逐页复验并留截图证据
- [ ] `verify.ps1` 通过（见 AGENTS.md）
- [ ] 相关文档已更新

## 不做
