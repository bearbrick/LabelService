# T-019 拼版设计器：拖拽单张标签到 A4 上排版

状态：待认领
负责人：—
里程碑：M3
依赖：T-013（复用画布的吸附、对齐、撤销等交互）、T-018（版式 JSON 规范）；保存到服务端依赖 T-014 的管理接口，之前可以导入导出 JSON 文件
设计书：§4 A4 拼版；ADR 0005

## 目标

设计人员把已经做好的单张标签拖到 A4 纸上，像排模板里的元素一样对齐，保存成版式；同一个模板以后既能单张打，也能按这个版式拼版打。

## 范围

可以新建、修改的文件：

- `frontend/src/`：拼版设计器页面和组件（纸张画布、模板列表、格子、版式属性面板）
- `frontend/src/model/layout.ts`：版式 JSON 的 TypeScript 镜像（契约副本，和 T-018 的后端模型一致）
- 建议把 T-013 里的吸附、对齐参考线、等间距分布、撤销重做抽成共用模块，模板设计器和拼版设计器都用

## 共享文件

改这些文件前先在交接记录里写明改什么；改动尽量小，单独成一个提交：

- `frontend/package.json`（如需新依赖）
- T-013 的画布交互模块（抽公共部分时，先和 T-013 的负责人在交接记录里对齐）

## 验收标准

- [ ] 新建版式：选纸张（A4、A5、自定义）和一个已发布的模板，格子尺寸取模板尺寸；左侧只列出尺寸相同的模板
- [ ] 拖入模板生成格子，格子里显示模板的真实预览（样例值）；可以拖多次
- [ ] 吸附网格、对齐参考线（格子之间、格子和纸边）、等间距分布、方向键微调 0.1 mm、撤销重做
- [ ] 自动排列：输入行数、列数、页边距、间距一键排满；格子可旋转 90°
- [ ] 格子显示序号；可以按“先行后列”“先列后行”重新编号，也可以手动调整
- [ ] 格子越界或重叠时标红，不能保存
- [ ] 打印校准：生成测试页（格子边框和中心十字）PDF，填写 X、Y 偏移
- [ ] 预览：样例值单页预览；上传一批数据预览多页效果（调用 T-018 的接口）
- [ ] 性能：A4 上 24 个格子、每个格子 20 个元素时，拖拽 ≥ 50 帧/秒（格子预览缓存成位图）
- [ ] 产出的版式 JSON 能被后端解析，格子位置和服务端 PDF 偏差 ≤ 0.2 mm
- [ ] `verify.ps1 -Part frontend` 通过；改了版式镜像时跑全量（见 AGENTS.md）

## 不做

- 模板嵌套（T-020，二期）
- 版式的版本管理（版式不分版本，修改立即生效）
