# T-019 拼版设计器：拖拽单张标签到 A4 上排版

状态：待验收
负责人：Claude 2026-10-10
里程碑：M3
依赖：T-013（复用画布的吸附、对齐、撤销等交互）、T-018（版式 JSON 规范）；保存到服务端依赖 T-014 的管理接口，之前可以导入导出 JSON 文件
设计书：§4 A4 拼版；ADR 0005

## 目标

设计人员把已经做好的单张标签拖到 A4 纸上，像排模板里的元素一样对齐，保存成版式；同一个模板以后既能单张打，也能按这个版式拼版打。

## 范围

可以新建、修改的文件：

- `frontend/src/`：拼版设计器页面和组件（纸张画布、模板列表、格子、版式属性面板）
- `frontend/src/model/layout.ts`：版式 JSON 的 TypeScript 镜像（契约副本，和 T-018 的后端模型一致）
- 建议把 T-013 里的吸附、对齐参考线、等间距分布、撤销重做抽成共用模块，模板设计器和拼版设计器都用

## 验收标准

- [x] 新建版式：选纸张（A4、A5、自定义）和一个已发布的模板，格子尺寸取模板尺寸；左侧只列出尺寸相同的模板
- [x] 拖入模板生成格子，格子里显示模板的真实预览（样例值）；可以拖多次（T-021 复核：已用真实的 HTML5 拖放验证）
- [x] 吸附网格、对齐参考线（格子之间、格子和纸边）、等间距分布、方向键微调 0.1 mm、撤销重做
- [x] 自动排列：输入行数、列数、页边距、间距一键排满；格子可旋转 90°
- [x] 格子显示序号；可以按“先行后列”“先列后行”重新编号，也可以手动调整
- [x] 格子越界或重叠时标红，不能保存
- [x] 打印校准：生成测试页（格子边框和中心十字）PDF，填写 X、Y 偏移
- [x] 预览：样例值单页预览；上传一批数据预览多页效果（调用 T-018 的接口）
- [x] 性能：A4 上 24 个格子、每个格子 20 个元素时，拖拽 ≥ 50 帧/秒（格子预览缓存成位图）（T-021 复核：按每帧绘制耗时判断，24 格 × 20 元素时每帧 P95 1.0 ms、最大 4.7 ms，预算 20 ms；逐帧帧率没有实测，浏览器窗格隐藏时 rAF 暂停，属环境阻塞）

- [x] `verify.ps1 -Part frontend` 通过；改了版式镜像时跑全量（见 AGENTS.md）

### 2026-10-10 · Claude

**做了什么**

- 入口：顶栏“资源”菜单的“拼版版式”，`#/layouts` 是列表，`#/layouts/编码` 是设计器（`pages/LayoutsPage.vue`）。新建时选纸张（A4、A5 纵横、自定义）和一个已发布的模板，格子尺寸取模板尺寸，按纸张排满、整体居中，默认编码如 `A4_100x60_2x4`。
- 纯逻辑 `model/layout.ts`：版式 JSON 的镜像、越界和重叠检查（规则、容差、提示语和服务端 `LayoutValidator` 一致）、自动排列、按纸张算最多几行几列、重新编号、手动调序、页数。`tests/checks.ts` 补了 15 项检查；后端 `ContractChecks` 按属性名核对镜像。
- 画布 `editor/sheetStage.ts`：格子里画服务端缩略图（样例值渲染的位图），按格子旋转摆放；拖动时选中的格子一起动，用 `editor/snapping.ts` 吸附到其他格子、纸边、网格并画参考线；从左侧拖模板到纸上生成格子（落点是格子中心）。
- 状态 `stores/sheet.ts`：所有修改走这里并记撤销（`editor/history.ts`），对齐、分布直接用 `editor/arrange.ts`（改成接受任意矩形）。
- 组件 `components/sheet/`：工具栏和快捷键（Ctrl+Z/Y/A/D、Delete、R 旋转、方向键 0.1 mm、Shift 1 mm、Ctrl+S 保存）；左侧同尺寸模板和自动排列；右侧版式属性、选中格子的 X/Y/旋转/序号、打印偏移、裁切线、启用、问题列表；预览和测试页显示在对话框里（PNG 直接显示，PDF 用浏览器自带的查看器），可以下载。
- 顺手修了工作台的一个 bug（我在 T-010 留下的）：服务端不输出 null，今日没有单张调用时 `p95Ms` 是 undefined，工作台报错白屏。

**验证**

- 前端检查 69 项、`npm run build`、完整 `verify.ps1` 通过（后端 398 项，含前端版式镜像的检查）。
- 浏览器里实测（临时数据目录，测完删除）：打开示例版式，方向键把第 1 格右移 0.3 mm 后和第 2 格重叠，两格标红、显示“1 个问题”、保存变灰，撤销后恢复“已保存”；自动排列转 90° 得到 3 列 × 2 行，服务端预览和画布一致；拖动格子按网格吸附；拖入模板（用合成的 drop 事件）加出第 9 格并选中；新建 A5 横向版式、Ctrl+S 保存后开放接口立即能用（5 张 2 页）；先列后行重新编号；打印测试页和上传 7 条数据的多页预览都显示在对话框里；未保存离开时提示；删除版式。
- 性能：24 个格子（A4 上用自动排列临时排 6 × 4），移动一个格子并同步重画，35% 和 100% 缩放下每帧都约 0.5 ms（约 2000 帧/秒）。格子画的是位图，和模板元素多少无关。
- 位置偏差：画布和服务端用的是同一份版式 JSON 里的坐标；服务端按坐标放格子的偏差由 T-018 的检查逐格验证（最大 0.048 mm），所以“≤ 0.2 mm”满足。
