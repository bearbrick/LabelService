# T-020 模板嵌套（二期）

状态：待认领
负责人：—
里程碑：二期
依赖：T-008（模板版本）、T-013（设计器）
设计书：§1 初版不做；ADR 0005

## 目标

把一个已发布的模板作为元素放进另一个模板，比如 A4 唛头里放一个现成的箱标，改箱标模板后发布新版本即可复用。初版的 A4 拼版（T-018、T-019）已经覆盖“同一个标签排满一张纸”，本任务解决的是“不同模板组合成一个模板”。

## 范围

可以新建、修改的文件：

- `backend/src/LabelService.Contracts/`：新增元素类型“嵌入模板”（引用模板编码和**固定的版本号**、字段映射）
- `backend/src/LabelService.Server/`：发布时把嵌入的模板**展开成普通元素**（坐标换算、字段合并），生成时不再有嵌套
- `frontend/src/`：从模板库拖入、整体移动缩放、字段合并界面；嵌入的模板在画布上缓存成位图
- 两边检查程序：补嵌套检查

## 共享文件

- 契约文件（新增元素类型属于向后兼容的契约变更，按 AGENTS.md §6.4 同一个提交改齐）

## 验收标准

- [ ] 嵌入时锁定子模板的版本号；子模板发布新版本后，父模板要手动升级才生效
- [ ] 字段合并：同名字段共用一个值，也可以加前缀区分；合并结果在数据源定义页可见
- [ ] 只允许嵌套一层；发布时检查循环引用（A 套 B、B 又套 A）
- [ ] 发布时展开：生成同一个标签的耗时和“直接画出来的等价模板”相差不超过 5%
- [ ] 设计器里拖动嵌入的模板 ≥ 50 帧/秒
- [ ] `verify.ps1` 全量通过（见 AGENTS.md）

## 不做

- 多层嵌套
