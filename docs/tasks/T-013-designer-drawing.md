## 目标

像做 PPT 一样画标签：7 种元素拖入画布，选择、移动、缩放、旋转、吸附、对齐、撤销重做、快捷键全部可用。这是初版最重要的体验。

## 范围

可以新建、修改的文件：

- `frontend/src/` 下全部文件（现有骨架只能显示和拖动，可以按需重构）
- 建议拆分：`components/`（画布、工具栏、元素库、图层、属性面板）、`stores/`（模板状态与撤销栈）、`model/`（已有，契约镜像）
- 浏览器端条码预览用 bwip-js（已在依赖里）

## 共享文件

- `frontend/src/model/template.ts`：契约镜像，改动属于契约变更（见 AGENTS.md）

## 验收标准

- [x] 设计书第 4 节“交互清单”全部实现：添加、选择、移动与缩放、旋转（条码只允许直角）、吸附与参考线、对齐与分布、编辑文本（`{{` 字段补全）、复制、撤销重做（≥ 50 步）、层级与锁定、视图缩放平移、预览切换
- [ ] 文本的换行、shrink 规则与服务端一致（同一模板位置偏差 ≤ 0.2 mm，待 T-001、T-016 后验证）——规则已按规范实现，等服务端文本渲染和字体下载完成后对比
- [x] 100 个元素时拖拽 ≥ 50 帧/秒（脚本实测，见交接记录；验收时可再用 Chrome 性能面板复核）
- [x] 产出的 JSON 能被服务端解析（用 ContractChecks 同样的规则：字段 key 唯一、元素 ID 唯一、绑定只引用已定义字段）
- [x] `npm run build` 通过（含 vue-tsc 类型检查）
- [x] `verify.ps1` 通过（见 AGENTS.md）
