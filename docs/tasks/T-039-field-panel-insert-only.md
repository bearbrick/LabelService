## 目标

用户反馈：设计页左侧的“字段”和模板工作区的“数据源”页重复了，保留数据源比较好。左侧“字段”原来能展开编辑名称、类型、样例值、必填，还能快速添加字段，和数据源页功能重叠，改的地方多了容易乱。改成：字段的新增和修改只在数据源页；设计页左侧“字段”只保留数据源页做不到的事——把字段拖到画布、拖到条码上绑定、双击插入到选中的文本，并给一个“去数据源”的按钮。
