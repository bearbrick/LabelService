# T-036 模板多了以后的模板树和模板库

状态：进行中

依赖：T-027
设计书：§designer（管理后台布局）

## 目标

用户问“未来模板成千上万怎么办”：左侧模板树把每个分组的每个模板都列出来，几百上千个时翻不动、不好看；模板库页面一次渲染全部卡片（每张都要加载缩略图）也会卡。改成：模板树只做导航，完整列表到模板库里分页看。

- 模板树：业务分组在模板少（不超过 30 个）时默认展开，多了默认收起，只展开当前模板所在的分组；每组最多列 20 个最近修改的模板，再多显示“查看全部 N 个”进入模板库；顶部加“最近打开”（5 个，按账号记在浏览器里）。
- 搜索框：有关键字时不按分组，平铺列出匹配的模板（最多 30 个，编码完全相同、开头匹配的排前面），再多给“在模板库里查看全部结果”。
- 模板库：卡片和列表都分页，每页 48 个。
