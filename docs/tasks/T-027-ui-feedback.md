### 2026-10-12 · Claude

**做了什么**（用户 2026-10-11 看界面后提的六条，字体上传另开 T-028）：

- 模板树拖宽：右边缘有拖动手柄（悬停显示蓝线），220～560px，同时不超过窗口宽度减 600；双击或 Home 恢复 280px，方向键每次 16px；宽度记在浏览器本地（`composables/useSidebarWidth.ts`），窄屏抽屉里固定 280px、不显示手柄。
- 素材格子：原来格子是 grid 布局，自动行高算不出图片 max-height 的百分比，方形素材（qcpass，160×160）显示成 83×83、撑出 60px 的格子；改成 flex 后 46×46，和其他格子一样大。
- 工作台滚动条：最近的操作占满剩下的高度、在自己的框里滚动（表头固定）；图表限宽 760px（宽屏上不再变高，坐标文字也不再放大）；“生成最多”“最慢”两个排行合成一个框、用按钮切换；去掉工作台多余的面包屑，间距收紧。实测 1920×1080、1920×950（1080 屏去掉浏览器边框后的大小）、1440×900 都没有整页滚动条，1920×950、1440×900 时最近的操作分别能看到 3、2 行；1366×768 这种矮屏还会整页滚动 57px（放不下）。
- 下拉框：全部 34 个下拉框都用 `.sel`，统一换成和图标一致的细箭头（离右边 10px）；浏览器支持可定制下拉框时（`appearance: base-select`，Chrome / Edge 135 起，本机 Edge 155、应用内浏览器 Chromium 152 都支持），展开的列表也是白底圆角、选中项浅蓝；不支持的浏览器用原生列表。“更换业务分组”弹窗从 420px 改成标准的 600px（只有它是窄弹窗里放了下拉框的）。
- 登录页公司信息：系统信息加“登录页标语”“登录页说明”两项（可以换行），登录页左栏标语上方显示所属公司（没填时显示 LABEL SERVICE），去掉“内部工具”。系统信息页的效果预览加了登录页左栏的缩小预览。后端 PUT 改成“不传的项不改”，避免旧前端把新加的项清空。

**验证**：后端检查 462 项（新增 2 项：登录页标语换行、只改部分项）；前端检查 71 项、类型检查通过；21 个页面在 1440、1280、768 宽下自动检查 0 个问题，弹窗 20 个通过（另 2 个是当前没有草稿、发布和放弃改动按钮不可用）；无头 Edge 截了下拉框展开、更换业务分组、登录页、工作台、系统信息页。`verify.ps1` 全量通过（后端 462、调用端 47、前端 71）。

**顺带说明**：查 Edge 版本时误用了 `msedge.exe --version`，它在 Windows 上会在现有的 Edge 会话里打开一个窗口或标签页，没有别的影响。
