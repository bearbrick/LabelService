## 目标

用户反馈：“调用代码”最好写全一点，比如直接打印的话怎么调用打印机。原来的代码生成标签、存到临时目录就结束了。改成按输出格式接着写出发送到打印机的代码：

- ZPL：`NetworkPrinter.SendAsync` 发给网络标签打印机（TCP 9100），注释里给出 USB 打印机用 `WindowsRawPrinter.Send` 按 RAW 写入打印队列的写法。
- PNG：`PrintDocument` 按标签原尺寸打印（像素 ÷ DPI），批量是 ZIP，逐张打印。
- PDF：交给本机的 PDF 阅读器打印（`Verb = "print"`）。

打印机地址、名称写成类里的常量；打印出错（连不上、名称不对、没有 PDF 阅读器）单独 catch，提示标签文件已经保存、可以重打。
