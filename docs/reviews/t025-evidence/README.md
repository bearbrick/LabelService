## 自动检查的结果

在浏览器里对 20 个页面逐个打开后量 DOM，检查五类问题：页面横向滚动、文字被裁掉且没有悬停提示、下拉框文字被截断、内容被纵向裁掉或超出窗口、文字和控件互相重叠。

页面：工作台、模板库（全部、某个业务）、模板工作区的设计、数据源、接口调试、版本记录（两个模板）、业务分组、画布预设、拼版版式列表和拼版设计器、素材与字体、调用方与密钥、接口调试、调用日志、操作日志、用户、角色、个人设置。

弹窗：新建模板、复制模板、删除确认（模板、预设、版式）、新建和编辑业务、调用方、预设、用户、新建角色、新建版式、服务端预览、发布、更换业务分组、快捷键、放弃改动确认、调用详情抽屉、拼版预览、一次性密钥框。

改变窗口大小：设计器和拼版设计器的画布、标尺跟着容器变化（如 1920→1280 时画布 1298×728 → 658×368，标尺同步）；停在“适应窗口”时重新适应（1280→1920 时 120% → 279%），手动缩放过就保持（放大到 348% 后缩小窗口仍是 348%）；拼版设计器同样（50% → 66%，手动 83% 保持）。
