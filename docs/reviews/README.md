# 历史评审与证据

本目录保留开发期的评审、整合过程和关键截图。每篇结论只针对文中固定的提交、机器与日期，不代表最新 main 已重新通过全部浏览器、性能或现场验收。当前状态看 [定版清单](../release-readiness.md)，复测入口看 [测试说明](../testing.md)。

| 记录 | 内容 |
| --- | --- |
| [一期评审](phase1-review.md) | 渲染、接口、升级、性能和现场验收边界；后续多项功能已继续实现 |
| [分段按钮](T-029-segmented-review.md) | 历史页面尺寸与分段布局检查 |
| [页面兼容整合](T-030-page-compatibility.md) | 当时固定分支、冲突与兼容性 |
| [功能整合](T-031-functional-integration.md) | 源码登记、SQLite 恢复、请求竞态 |
| [布局整合](T-032-layout-integration.md) | 导航/视口行为及隔离整合过程 |
| [显示证据说明](t025-evidence/README.md) | 历史页面和演示程序截图的含义 |

不同任务的历史名称、工作区路径和提交 SHA 保留用于追溯。仓库外临时证据路径可能只在当时机器存在；新验收重新生成，不要求复制旧工作区或恢复旧临时账号。

只合并字节一致的重复截图，指向保留的同一份证据；不删除唯一截图、不把历史“未验证”改写成当前“已通过”。完整自动化测试继续保留在 frontend、backend、client 的 tests 中。
