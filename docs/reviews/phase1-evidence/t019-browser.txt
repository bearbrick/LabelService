# T-019 拼版设计器真实交互复核（T-021）

环境：内置浏览器（Chromium），视口模拟 1280×800；本地开发服务 http://localhost:5080（临时数据目录，测完删除）+ Vite 开发服务器 5173；admin 首次登录改为临时测试密码。
测试数据（脚本经管理接口创建）：模板 SMALL_BOX_20，70×37 mm、20 个元素（外框、9 段文本、2 条线、一维码、二维码、2 个图标、徽标框等），已发布 v1；版式 A4_70x37_3x8，A4 上 3 列 × 8 行 = 24 格。

## 真实鼠标拖动格子（computer left_click_drag，CDP 输入，事件 isTrusted = true）
事件：pointerdown 1、pointermove 2、pointerup 1，全部 isTrusted:true，落点 (749,355) 在第 5 格中心。
结果：第 5 格从 (70, 37.5) mm 移到 (95, 74.5) mm——Y 吸附到第 3 行上沿 74.5，X 按 1 mm 网格取整；状态从“已保存”变成“2 个问题”（和相邻格子重叠，标红）；Ctrl+Z 撤销后回到 (70, 37.5)、“已保存”。
缩略图未加载（页面目录还没有新模板）和已加载两种情况都拖过，结果一致。

## 真实 HTML5 拖放（左侧模板卡片拖到画布）
事件：dragstart (418,378) → dragover ×2 → drop (750,499) → dragend，全部 isTrusted:true。
结果：新增第 25 格，位置 (70.2, 128.2) mm（落点是格子中心），状态“4 个问题”（和周围格子重叠）；Ctrl+Z 撤销后回到 24 格、“已保存”。T-019 交接里“真实拖放模拟不了、请人工拖一次”的一项已用真实输入验证。

## 拖动性能（24 格 × 每格 20 个元素，格子画缩略图位图）
同步计时 300 次（预热 20 次），缩放 1.586 px/mm，画布 398×519，24 个缩略图（360×190）都已加载：
  三个图层整体重画：P50 0.4 ms，P95 1.0 ms，最大 4.7 ms
  移动一个格子 + 重画：P50 0.3 ms，P95 0.7 ms，最大 1.3 ms
50 帧/秒的每帧预算是 20 ms。（内置浏览器窗格隐藏时 requestAnimationFrame 和 image.decode() 都暂停，逐帧帧率改在下面的可见窗口里测。）
窗格显示时的一次真实拖动：rAF 间隔平均 16.7 ms（60 Hz 显示器），每次重画 0.6–0.9 ms（当时缩略图未加载）。

## 逐帧帧率（补测：可见的 Edge 窗口）
环境：本机 Edge 155，临时用户目录，关闭窗口遮挡检测和后台节流（--disable-features=CalculateNativeWinOcclusion 等），窗口 1418×869 CSS 像素、DPR 1.5；同一个本地开发服务和测试数据。
方法：Chrome DevTools 协议的 Input.dispatchMouseEvent 发真实鼠标事件——在第 5 格中心按下，240 次 mouseMoved（每 8 ms 一次，沿 120×80 像素的圆走一圈），松开；页面里记 requestAnimationFrame 时间戳和每次图层重画的耗时；拖完 Ctrl+Z 撤销。24 个缩略图都已加载（Konva.Image 24 个）。
空闲时 rAF 间隔中位数 17.9 ms（这个窗口的出帧上限约 56 帧/秒）。
适应窗口（1.825 px/mm）：拖动 5.9 秒，332 帧，56.3 帧/秒；帧间隔 P50 18.0、P95 18.1、P99 18.5、最大 18.5 ms，超过 20 ms 的 0 帧；dragmove 239 次；每次重画 P50 0.1、P95 0.7、最大 1.6 ms。撤销后回到 (70, 37.5)、“已保存”。
放大到 114%（4.303 px/mm，Ctrl+滚轮）：56.0 帧/秒；帧间隔 P50 18.0、P95 18.1、最大 18.5 ms，超过 20 ms 的 0 帧；每次重画 P95 0.7、最大 1.4 ms。
结论：拖动时帧率等于窗口的出帧上限，一帧都没掉；≥ 50 帧/秒满足。

## 模板详情的“可用版式”（设计书第 4 节）
SMALL_BOX_20（70×37）：可用版式 A4_70x37_3x8（提示“A4 · 70×37 · 3 列 × 8 行，24 格”）
BOX_LABEL（100×60）：可用版式 A4_100x60_2x4；点击后进入 #/layouts/A4_100x60_2x4 的拼版设计器
A4_SHIPPING_MARK（210×297）：可用版式 无（提示“还没有格子尺寸和这个模板相同的拼版版式”）
停用 A4_70x37_3x8 后再打开 SMALL_BOX_20：可用版式 无（只列启用的版式）
请求：GET /api/admin/layouts?slotWidth=70&slotHeight=37 等，均 200。

## 其他观察
- 用接口新建模板后，已打开的页面要刷新才会在左侧和拼版设计器里出现（目录在登录时加载一次），属现有行为。
- 打开拼版设计器时同一个缩略图地址连续请求两次（都是 200），可以合并，影响很小。
- 浏览器控制台 3 条 401 是测试脚本手动请求缩略图没带令牌，应用自己的请求都是 200。
